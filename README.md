# AgileBuild Demo

Aplicación web para gestión ágil de proyectos de diseño.

## Publicación
Este repositorio está preparado para publicarse como sitio estático.

Archivo principal:
- `index.html`

## Flujo recomendado
1. Trabajar los cambios en GitHub.
2. Conectar el repositorio con Netlify.
3. Usar la rama `main` como producción.
4. Cada cambio aprobado en `main` genera una nueva publicación.

## Datos
La versión actual usa `localStorage` en el navegador.
La siguiente etapa será migrar los datos compartidos a Supabase para colaboración multiusuario.
